# CavityFEM（公開版 v0.1.8）

STEP形状から共振周波数、内部Q（Qi）、ポートごとの外部Q（Qc）、participation、電場分布、同軸ポートのS11を求めるローカル解析アプリです。NGSolve / Netgenを使用します。

**[Macアプリをダウンロード](https://github.com/qupqubit/cavity-lab-public/releases/latest/download/CavityFEM-macOS.zip)** · [利用ページ](https://qupqubit.github.io/cavity-lab-public/) · [Windows・ブラウザ版ZIP](https://github.com/qupqubit/cavity-lab-public/releases/latest/download/cavity-lab-public.zip)

v0.1.8ではアプリの表示名を **CavityFEM** に変更し、指定されたキャビティ画像をアイコンに使用しました。また、計算中に所要時間カードへ残り時間が表示されない問題を修正しました。計算履歴の保存先は引き継ぎます。

## Macアプリの起動

macOS 12以降のApple Silicon・Intel向けUniversalアプリです。Pythonを同梱しているため、PythonやGitの導入、clone、GitHubログインは不要です。Intel Macでの実機動作は未検証です。

1. Mac用ZIPをダウンロードし、全体を展開します。
2. `CavityFEM.app` を「アプリケーション」フォルダなどに移動して開きます。
3. 初回はインターネットからFEMライブラリを準備します。数分かかることがあるため、アプリ内の状態表示を確認して待ちます。
4. 準備が終わると同じウィンドウに解析画面が表示されます。「円筒サンプルを読み込む」か、ファイル選択でSTEPを読み込んで使います。

解析画面、STEPの選択、結果の保存、ログ閲覧はアプリ内で行います。外部ブラウザやターミナルを開く必要はありません。通常の計算と保存は、このアプリを起動したMacで実行します。初回準備後はローカルで利用できますが、更新に伴うライブラリ追加時には再び通信が必要になる場合があります。

### 終了・保存先・更新

アプリを閉じると、実行中の計算を停止してから終了します。保存済みデータは残ります。STEP・設定・結果の保存先は `~/Library/Application Support/Cavity Lab/data` です。「表示」メニューの「計算データを Finder で表示」で確認でき、ログは「ログを開く」でアプリ内に表示します。

更新時は計算を終えて旧アプリを終了し、新しい `CavityFEM.app` を配置して、以後はこちらを開きます。旧名の `Cavity Lab.app` が残る場合は、古い版と同時に起動しないでください。データはアプリ本体の外にあるため、そのまま引き継ぎます。保存先に残る `Cavity Lab` という名前は、既存の履歴との互換性のため意図的に維持しています。保存先フォルダの名前を変更する必要はありません。ブラウザ版から移行する場合は、両方を停止してから旧フォルダの `data/` をこの保存先へコピーできます。既存の保存先がある場合は、先にバックアップしてください。

### Appleの確認警告が出る場合

この配布版はAppleのDeveloper IDによる署名・公証を受けていません。アプリ形式でも、初回にGatekeeperの確認警告が出る場合があります。「Appleはマルウェアが含まれていないことを検証できませんでした」はマルウェア検出の通知とは異なり、安全性の保証でもありません。

[このプロジェクトの配布ページ](https://github.com/qupqubit/cavity-lab-public/releases)から取得したファイルであることを確認し、実行を許可する場合に限り、次の操作を行ってください。

1. 警告を閉じ、Appleメニュー →「システム設定」→「プライバシーとセキュリティ」を開きます。
2. 下へスクロールし、`CavityFEM` のブロック表示にある「このまま開く」を選びます。
3. 認証と確認画面の内容を確認し、「開く」を選びます。

ボタンがない場合はアプリをもう一度開いて警告を閉じ、設定を確認してください。組織管理のMacでは管理者の制限がある場合があります。マルウェア検出や破損を明示する警告には、この手順を流用しないでください。[Apple公式の説明](https://support.apple.com/ja-jp/102445)を確認してください。Gatekeeperの無効化や一括の隔離属性削除は不要です。

## Windows・ブラウザ版

[ブラウザ版ZIP](https://github.com/qupqubit/cavity-lab-public/releases/latest/download/cavity-lab-public.zip)も利用できます。Windows x86-64とmacOSが対象です。Windows ARMのネイティブ実行は対象外で、Windows実機でのFEM計算は未検証です。

1. [Python公式サイト](https://www.python.org/downloads/)から64ビットのPython 3.9〜3.12を導入します（3.12推奨）。WindowsではPython Launcherも導入します。
2. ZIP全体を書込み可能なフォルダへ展開します。
3. Windowsは `launch.bat`、macOSは `launch.command` を開きます。
4. 初回のライブラリ準備後、同じPCのブラウザで `http://127.0.0.1:8768/` が開きます。

計算中は起動したターミナル／コマンド画面を開いたままにしてください。停止はそこでCtrl+Cです。起動中は[解析画面を開く](http://127.0.0.1:8768/)リンクも使えますが、リンクだけで停止中のプログラムを自動起動することはできません。データは展開フォルダ内の `data/` に保存します。更新時は旧版を停止し、新しいZIPを別フォルダに展開して、必要なら旧版の `data/` をコピーします。

Macの `launch.command` にAppleの確認警告が出る場合は、上の手順でそのファイル名を確認します。これとは別に「適切なアクセス権がない」と表示される場合は、ターミナルへ `/bin/bash ` と入力し、展開した `launch.command` をドラッグしてEnterを押します。セキュリティ設定を自動変更する処理はありません。

## 使い方

- STEPを読み込むと、形状から解析領域を自動選択します。判定結果を確認し、必要なら「解析する領域」から空隙抽出／入力ソリッドを手動で選べます。
- 固有モード、メッシュ、材料・損失条件を指定します。Qiには動作条件に応じた表面抵抗や誘電損失などの入力が必要です。
- CAD上の面を選び、汎用同軸アンテナまたは外部境界を追加します。中心導体の突出長さは0 mmから変更・掃引できます。
- 「指定した全開口の流出電力・空洞Qc」は、指定した接続ごとに蓄積エネルギーと流出電力からQcを計算します。形状の全穴を自動で正しく認識した保証はないため、対象面を確認してください。
- 結果で各モードの周波数、Qi、Qc、participation、電場断面を確認します。同軸ポートがある場合は広帯域S11も計算できます。計算時間の見積りと進捗を表示します。

計算中の所要時間カードには、残り時間、完了時刻（日本時間）、予測幅、現在の処理を表示します。表示はサーバーからの進捗と経過時間に応じて更新され、順番待ちの計算や、履歴から開いた実行中の計算にも反映されます。推定できない間はその状態を表示します。所要時間は目安であり、実際の完了時刻を保証するものではありません。

[計算方法と適用範囲](manual/methods.md)をご確認ください。広帯域S11だけで最低次モードを証明することはできません。励振と結合しないモードがあるため、低周波側からの固有値探索と組み合わせます。

### メモリに応じた計算規模の制限

計算規模の上限は、計算するPCの物理メモリと空き容量から求めます。画面の「現在のPC・設定のメモリ」に総容量・利用可能量・解析予算・現在の次数とモード数での自由度上限を表示します。macOSとWindowsで同じ方針を使用し、計算開始時にも空き容量を調べ直します。

OSや他のアプリ用に総容量の15%または2 GiBの大きい方を残します。解析予算は「総容量の50%」「利用可能量の65%」「利用可能量から確保分を引いた量」の最小値です。スワップは含めません。メッシュ作成後・行列分解前に概算ピーク量を確認し、実行中は約0.5秒ごとに計算プロセスの使用量とシステムの空き容量を監視します。上限超過や監視不能時は当該計算を停止します。

自由度からのメモリ見積りは保守的な概算で、疎行列の形状依存性を厳密に予測するものではありません。監視間隔中の急増などによるメモリ不足を完全には防げません。メモリ不足を理由にメッシュ寸法・次数・解析領域を自動変更することはありません。上限を超え、次数が2または3の場合は、まず次数1で計算規模を減らして試してください。最大要素寸法を大きくする方法もありますが、小さな穴・曲面・細い隙間などが局所的な細分化を要求するため、自由度があまり減らない場合があります。次数1の結果をそのまま最終値とせず、次数とメッシュを変えた収束確認が必要です。金属本体のSTEPには「金属モデルから空隙を抽出」を選び、意図した空洞を選択してください。

### 計算スレッド数と後処理

実行PCで利用可能なCPUスレッド数を取得し、その80%（小数点以下切捨て、最低1）を初期値にします。例えば8スレッドなら6、12スレッドなら9です。検出数と推奨値を画面に表示し、手動変更できます。履歴を開いた場合は保存したスレッド数を優先します。これは並列処理に使うスレッド数の設定であり、CPU使用率を常に80%に制御するものではありません。メモリ予算は従来どおり独立して確認します。

後処理のNGSolve積分にも指定スレッド数を適用します。壁面損失・材料と表面のparticipation・蓄積エネルギーの積分を、同じメッシュと電場を共有するスレッドで処理します。Pythonプロセスをスレッド数分だけ起動する方式ではありません。

電場断面もソルバー内部の一括評価を利用します。領域外の点は評価前に除き、従来と同じマスクと3断面共通の正規化を保ちます。一括評価を利用できない場合は従来の点ごとの評価へ戻ります。モードごとに巨大な行列を別プロセスへ複製することはありません。

直列のPython処理やファイル書き出し、固有値反復の一部は残るため、全工程が常に指定コア数で動いたり、その数に比例して速くなったりする保証はありません。結果の `timings.postprocess_s` で後処理時間を確認できます。浮動小数点の加算順序が変わるため、スレッド数によって末尾桁が異なることがあります。

### 現在のメモリと計算時の記録

「現在のPC・設定のメモリ」は、今のPCの空き容量と、画面で指定した次数・モード数から求める値です。「再取得」で調べ直せます。STEPが未選択でも、材料・境界など他の設定が未入力や不正でも、次数とモード数が有効ならメモリ情報を取得できます。

選択した計算のメモリ診断は、その計算時に記録した値として別に表示します。メッシュ作成後のメモリ確認で停止した場合も、実際に作成された総自由度、その自由度から求めた推定ピーク、適用した予算と上限を保存し、履歴から確認できます。推定ピークは使用量の実測値ではありません。記録のない項目は未計測として表示し、現在のPCの値で置き換えません。

## 解析領域の自動選択

「解析する領域」の初期値は「自動判定」です。STEPの内側に包囲された空隙や貫通孔の候補がある場合は、空隙抽出を選びます。円筒の外周と外接直方体の間の空間などは、外接直方体の辺との接触から除外し、残った候補のうち最大の領域を選びます。候補がない場合は入力中の最大ソリッドを選択します。選択結果と理由を画面に表示します。

STEP形状だけでは金属と真空の意味を確定できません。複数の空洞、外部空間につながる大きな側面開口、環状の真空領域などでは意図と異なる判定になり得ます。既存の2つの手動選択肢と領域の選択を残しています。自動判定後に領域番号を変更すると、その解析方式を手動指定として保持します。履歴は保存された解析方式と領域番号のまま復元し、再判定しません。

## 空隙から外部開口を自動設定する

「金属モデルから空隙を抽出」で新しく読み込むか解析領域を変更すると、「抽出した開口を自動で外部ポートにする」が有効になります。選択した空隙を金属の外接直方体で閉じた面（人工キャップ）を開口候補として登録し、候補がある場合は「指定した全開口の流出電力・空洞 Qc」を選択します。解析後の「損失・Participation」で各開口の流出電力とQc、全開口を合わせたQcを確認できます。

計算は `Qc,p = ω Ucavity / Pp`、合成値は `Qc = ω Ucavity / ΣPp` です。空洞bulk領域の電気・磁気エネルギーと各境界からの時間平均流出電力を使います。この解析モードではS11を計算しません。エネルギー／電力によるQの定義は[キャビティ共振器の解説](https://doc.comsol.com/6.3/doc/com.comsol.help.models.rf.cavity_resonators/cavity_resonators.html)にも記載されています。

自動ポートの初期境界は、外部の相対誘電率1、波動インピーダンス約376.73 Ωの一次放射近似です。カードで外部媒質やインピーダンスを変更でき、不要な面は除外できます。アンテナ取付面と手動の境界条件を優先します。開口候補が0件の場合は共振・Qiの解析に戻り、必要な開口を手動で指定できます。過去の計算を開いた場合は、保存済みの境界条件をそのまま復元します。計算した流出電力が数値評価の閾値未満の面は「流出微小・Qc未確定」と表示し、無限大とは断定しません。

この認識は外接直方体上の切断面に基づきます。モデルの外側の空間も空隙候補になるため、目的の空洞を選んでいるか確認してください。直方体内にある穴の口を一つずつ自動で分離したり、実機の全接続を保証したりする処理ではありません。局所放射境界はPMLや外部空間の厳密な解析ではなく、特に遮断以下の細い穴や斜めに流出する場では、境界位置・モデル範囲・メッシュを変えてQcを確認する必要があります。

## データと検索表示

MacアプリのSTEP・設定・結果は `~/Library/Application Support/Cavity Lab/data`、起動ログと計算環境は同じ `Cavity Lab` フォルダ内に保存します。ブラウザ版は展開フォルダ内の `data/` を使います。解析APIはループバックで待ち受け、通常解析でデータを外部へ送信する処理はありません。配布ファイルの取得と初回ライブラリ導入には外部接続が必要です。

利用ページは `noindex, nofollow` を設定しています。アクセス制限や秘密リンクではありません。公開リポジトリと配布ファイルは誰でも閲覧・取得でき、GitHub検索や外部のリンクなどから発見され得ます。Google等の検索への非掲載を完全には保証できません。[Googleのnoindex仕様](https://developers.google.com/search/docs/crawling-indexing/block-indexing)

## 開発・再現

Python環境を準備した後に `python -m pytest` で検証します。テスト用には `pytest` と `httpx` が必要です。`python scripts/build_source_zip.py` は、実行環境・利用者データ・Git履歴を除いて配布ZIPを生成します。

ブラウザ版の任意設定として `CAVITY_FEM_PORT`、`CAVITY_FEM_DATA`、`CAVITY_FEM_PYTHON` を使用できます。通常は変更不要です。Macアプリの実行環境・接続先・データ保存先はランチャーが管理します。
