# キャビティ FEM（公開版）

STEP形状から共振周波数、内部Q（Qi）、ポートごとの外部Q（Qc）、participation、電場分布、同軸ポートのS11を求めるローカル解析アプリです。NGSolve / Netgenを使用します。

**[利用ページを開く](https://qupqubit.github.io/cavity-lab-public/)** · **[配布ZIPをダウンロード](https://github.com/qupqubit/cavity-lab-public/releases/latest/download/cavity-lab-public.zip)**

GitHub Pagesは案内とダウンロードの入口です。有限要素計算はブラウザを開いているPCのローカルプロセスで実行します。Gitやclone、GitHubログインは不要です。初回はPythonと計算ライブラリの導入が必要です。

## 起動

1. [Python公式サイト](https://www.python.org/downloads/)から64ビットのPython 3.9〜3.12を導入します（3.12推奨）。
2. 配布ZIPの全体を、書込み可能なフォルダへ展開します。
3. macOSは `launch.command`、Windows x86-64は `launch.bat` を開きます。
4. 初回の準備後、ブラウザで `http://127.0.0.1:8768/` が開きます。サンプル円筒を読み込んで解析できます。

導入後は起動ファイルを開くか、起動中なら利用ページの「このPCで解析画面を開く」を選びます。ブラウザのリンクだけで停止中のローカルプログラムを起動することはできません。起動したターミナルは計算中開いたままにしてください。停止はそこでCtrl+Cです。

### MacでAppleの確認警告が出る場合

この配布版の `launch.command` はAppleのDeveloper IDによる署名・公証を受けていません。ダウンロードしたファイルを初めて開く際に、Gatekeeperが実行を止めることがあります。「Appleはマルウェアが含まれていないことを検証できませんでした」は、マルウェア検出の通知とは異なりますが、安全性を保証する通知でもありません。

[このプロジェクトの配布ページ](https://github.com/qupqubit/cavity-lab-public/releases)から取得したファイルであることを確認し、実行を許可する場合は次の操作を行ってください。

1. 警告画面で「完了」を押します。
2. Appleメニュー →「システム設定」→「プライバシーとセキュリティ」を開き、下へスクロールします。
3. `launch.command` のブロック表示にある「このまま開く」を選びます。
4. 認証・確認画面の内容を確認して「開く」を選ぶと、ターミナルで初回準備が始まります。

「このまま開く」がない場合は起動ファイルをもう一度開いて警告を閉じ、設定を確認してください。組織管理のMacでは管理者の制限がある場合があります。Mac全体のGatekeeperの無効化や、一括の隔離属性削除は不要です。[Apple公式の説明](https://support.apple.com/ja-jp/102445)

この案内の追加は署名・公証の追加ではないため、最新版をダウンロードし直しても警告が出る場合があります。

### 「適切なアクセス権がない」という別のエラーの場合

Appleの確認警告ではなく実行権限エラーの場合は、ターミナルに `/bin/bash ` と入力し、展開した `launch.command` をドラッグしてEnterを押します。ランチャーの実行権限もZIP内に保存しています。セキュリティ設定を自動変更する処理はありません。

対応するPython用配布物を使用します。Windows ARMのネイティブ実行は対象外です。Windows用ランチャーを同梱していますが、Windows実機でのFEM計算は未検証です。

## 使い方

- STEPの解析領域を選びます。サンプルは真空領域そのものです。金属STEPからの空隙抽出も選べます。
- 固有モード、メッシュ、材料・損失条件を指定します。Qiには動作条件に応じた表面抵抗や誘電損失などの入力が必要です。
- CAD上の面を選び、汎用同軸アンテナまたは外部境界を追加します。中心導体の突出長さは0 mmから変更・掃引できます。
- 「指定した全開口の流出電力・空洞Qc」は、指定した接続ごとに蓄積エネルギーと流出電力からQcを計算します。形状の全穴を自動で正しく認識した保証はないため、対象面を確認してください。
- 結果で各モードの周波数、Qi、Qc、participation、電場断面を確認します。同軸ポートがある場合は広帯域S11も計算できます。計算時間の見積りと進捗を表示します。

[計算方法と適用範囲](manual/methods.md)をご確認ください。広帯域S11だけで最低次モードを証明することはできません。励振と結合しないモードがあるため、低周波側からの固有値探索と組み合わせます。

### メモリに応じた計算規模の制限

v0.1.2から、固定45万自由度の制限を、計算するPCの物理メモリと空き容量から求める制限に変更しました。画面の「現在のPC・設定のメモリ」に総容量・利用可能量・解析予算・現在の次数とモード数での自由度上限を表示します。macOSとWindowsで同じ方針を使用し、計算開始時にも空き容量を調べ直します。

OSや他のアプリ用に総容量の15%または2 GiBの大きい方を残します。解析予算は「総容量の50%」「利用可能量の65%」「利用可能量から確保分を引いた量」の最小値です。スワップは含めません。メッシュ作成後・行列分解前に概算ピーク量を確認し、実行中は約0.5秒ごとに計算プロセスの使用量とシステムの空き容量を監視します。上限超過や監視不能時は当該計算を停止します。

自由度からのメモリ見積りは保守的な概算で、疎行列の形状依存性を厳密に予測するものではありません。監視間隔中の急増などによるメモリ不足を完全には防げません。メッシュ寸法・次数・解析領域を自動変更することはありません。上限を超え、次数が2または3の場合は、まず次数1で計算規模を減らして試してください。最大要素寸法を大きくする方法もありますが、小さな穴・曲面・細い隙間などが局所的な細分化を要求するため、自由度があまり減らない場合があります。次数1の結果をそのまま最終値とせず、次数とメッシュを変えた収束確認が必要です。金属本体のSTEPには「金属モデルから空隙を抽出」を選び、意図した空洞を選択してください。

更新する場合は旧版の計算と起動用ターミナルを終了し、新しいZIPを別フォルダに展開して起動します。過去の履歴が必要なら、停止中に旧版の `data/` を新版へコピーします。起動時に追加の監視ライブラリも準備します。

### 計算スレッド数と後処理

v0.1.3から、後処理のNGSolve積分にも指定スレッド数を適用します。壁面損失・材料と表面のparticipation・蓄積エネルギーの積分を、同じメッシュと電場を共有するスレッドで処理します。Pythonプロセスをスレッド数分だけ起動する方式ではありません。

電場断面もソルバー内部の一括評価を利用します。領域外の点は評価前に除き、従来と同じマスクと3断面共通の正規化を保ちます。一括評価を利用できない場合は従来の点ごとの評価へ戻ります。モードごとに巨大な行列を別プロセスへ複製することはありません。

直列のPython処理やファイル書き出し、固有値反復の一部は残るため、全工程が常に指定コア数で動いたり、その数に比例して速くなったりする保証はありません。結果の `timings.postprocess_s` で後処理時間を確認できます。浮動小数点の加算順序が変わるため、スレッド数によって末尾桁が異なることがあります。

### v0.1.4のメモリ表示と画面更新

「現在のPC・設定のメモリ」は、今のPCの空き容量と、画面で指定した次数・モード数から求める値です。「再取得」で調べ直せます。STEPが未選択でも、材料・境界など他の設定が未入力や不正でも、次数とモード数が有効ならメモリ情報を取得できます。

選択した計算のメモリ診断は、その計算時に記録した値として別に表示します。メッシュ作成後のメモリ確認で停止した場合も、実際に作成された総自由度、その自由度から求めた推定ピーク、適用した予算と上限を保存し、履歴から確認できます。推定ピークは使用量の実測値ではありません。記録のない項目は未計測として表示し、現在のPCの値で置き換えません。

更新時に古いJavaScriptやCSSが残って表示が混在する問題を修正しました。旧版の計算を止め、起動用ターミナルを終了してから、新しいZIPを別フォルダへ展開し、新版の起動ファイルを開いてください。ランチャーが版を含むURLで画面を開き、画面ファイルにも内容に対応した識別子を付けて読み込みます。更新直後は古いタブを使い続けず、新しく開いた画面を使用してください。

## 空隙から外部開口を自動設定する（v0.1.5）

「金属モデルから空隙を抽出」で新しく読み込むか解析領域を変更すると、「抽出した開口を自動で外部ポートにする」が有効になります。選択した空隙を金属の外接直方体で閉じた面（人工キャップ）を開口候補として登録し、候補がある場合は「指定した全開口の流出電力・空洞 Qc」を選択します。解析後の「損失・Participation」で各開口の流出電力とQc、全開口を合わせたQcを確認できます。

計算は `Qc,p = ω Ucavity / Pp`、合成値は `Qc = ω Ucavity / ΣPp` です。空洞bulk領域の電気・磁気エネルギーと各境界からの時間平均流出電力を使います。この解析モードではS11を計算しません。エネルギー／電力によるQの定義は[キャビティ共振器の解説](https://doc.comsol.com/6.3/doc/com.comsol.help.models.rf.cavity_resonators/cavity_resonators.html)にも記載されています。

自動ポートの初期境界は、外部の相対誘電率1、波動インピーダンス約376.73 Ωの一次放射近似です。カードで外部媒質やインピーダンスを変更でき、不要な面は除外できます。アンテナ取付面と手動の境界条件を優先します。開口候補が0件の場合は共振・Qiの解析に戻り、必要な開口を手動で指定できます。過去の計算を開いた場合は、保存済みの境界条件をそのまま復元します。計算した流出電力が数値評価の閾値未満の面は「流出微小・Qc未確定」と表示し、無限大とは断定しません。

この認識は外接直方体上の切断面に基づきます。モデルの外側の空間も空隙候補になるため、目的の空洞を選んでいるか確認してください。直方体内にある穴の口を一つずつ自動で分離したり、実機の全接続を保証したりする処理ではありません。局所放射境界はPMLや外部空間の厳密な解析ではなく、特に遮断以下の細い穴や斜めに流出する場では、境界位置・モデル範囲・メッシュを変えてQcを確認する必要があります。

サンプルはパラメータから新しく生成した半径15 mm・高さ20 mmの円筒真空領域です。`scripts/generate_samples.py` で再生成できます。特定の実機、コネクタ製品、研究用CADを再現したものではありません。表面抵抗10 nΩなどの初期値は操作例であり、材質・温度から予測した値ではありません。

## データと検索表示

STEP、設定、計算ログ、結果は各PCの展開フォルダ内 `data/` に保存します。解析APIはループバックで待ち受け、通常解析でデータを外部へ送信する処理はありません。配布ファイルの取得と初回ライブラリ導入には外部接続が必要です。

利用ページは `noindex, nofollow` を設定しています。アクセス制限や秘密リンクではありません。公開リポジトリと配布ファイルは誰でも閲覧・取得でき、GitHub検索や外部のリンクなどから発見され得ます。Google等の検索への非掲載を完全には保証できません。[Googleのnoindex仕様](https://developers.google.com/search/docs/crawling-indexing/block-indexing)

## 開発・再現

Python環境を準備した後に `python -m pytest` で検証します。テスト用には `pytest` と `httpx` が必要です。`python scripts/build_source_zip.py` は、実行環境・利用者データ・Git履歴を除いて配布ZIPを生成します。

任意の設定として `CAVITY_FEM_PORT`、`CAVITY_FEM_DATA`、`CAVITY_FEM_PYTHON` を使用できます。通常は変更不要です。ポートを変更した場合は公開ページの既定リンクを使わず、起動時に表示されたURLを開いてください。
