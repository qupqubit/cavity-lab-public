キャビティ解析の起動方法

STEP 形状の共振周波数、Qi、各ポートの Qc、participation、電場分布をブラウザで確認します。計算とデータ保存は、このブラウザを使っているPCで行います。

このページは配布と起動手順の案内です。FEM 解析には、以下のアプリを同じPCで起動する必要があります。Git のインストールやリポジトリの clone は不要です。

アプリ一式をダウンロード（ZIP） 起動済みの解析画面を開く

対応：macOS / Windows。Python 3.9〜3.12 が必要です。初回の計算環境の準備にはインターネット接続を使用します。

初回の準備

  1. Python を用意する

    Python 3.9〜3.12 を使用します（3.12 推奨）。未導入の場合は、Python の公式サイトからインストールしてください。Windows では Python Launcher もインストールしてください。

  2. ZIP をダウンロードして、全体を展開する

    上のボタンからアプリ一式を取得し、ZIP をすべて展開してください。起動用ファイルだけを取り出さず、同梱のフォルダとファイルを一緒に置きます。

  3. このPCで起動用ファイルを開く

    macOS
    展開したフォルダ内の launch.command
    Windows
    展開したフォルダ内の launch.bat

    初回は必要な計算用ライブラリを準備します。処理が終わるまで待ち、表示された解析画面を使ってください。Macで「Appleは検証できませんでした」と表示された場合は、以下の警告への対処を確認してください。

  4. STEP を読み込んで解析する

    解析画面に STEP を読み込み、領域・材料・境界条件を確認して実行します。「円筒サンプルを読み込む」で、半径 15 mm・高さ 20 mm の真空円筒も試せます。材料損失や同軸寸法の初期値は例なので、対象に合わせて変更してください。

Macで「launch.command は開いていません」と表示されたら

この配布版の起動ファイルは、AppleのDeveloper IDによる署名・公証を受けていません。そのため、別のMacへダウンロードして最初に開く際に、Gatekeeperが実行を止める場合があります。「Appleはマルウェアが含まれていないことを検証できませんでした」という警告は、マルウェアが検出されたという通知とは異なります。ただし、安全性が保証されたという意味でもありません。

このプロジェクトの配布ページから取得したファイルであることを確認し、実行を許可する場合は次の操作を行ってください。

  1. 警告画面で「完了」を押します。
  2. Appleメニューから「システム設定」→「プライバシーとセキュリティ」を開き、下へスクロールします。
  3. launch.command がブロックされた旨の表示の横にある「このまま開く」を選びます。
  4. 認証と確認を求められたら内容を確認して「開く」を選びます。ターミナルが開き、初回準備が始まります。

「このまま開く」が出ない場合は、起動ファイルをもう一度開いて警告を閉じ、設定を確認してください。組織が管理するMacでは管理者の制限がある場合があります。Mac全体のGatekeeperを無効にする操作や、一括の隔離属性削除は不要です。Apple公式の説明

これは実行権限のエラーとは別です。「適切なアクセス権がない」と表示される場合の手順はREADMEを確認してください。案内を更新した配布ZIPでも、Appleの署名・公証が追加されたわけではありません。

次回から使うとき

展開したフォルダ内の起動用ファイルを開いてから、このPCの解析画面（127.0.0.1:8768）に接続します。利用中は、起動時に開いたターミナルまたはコマンド画面を閉じずに残してください。

「起動済みの解析画面を開く」は、動いているローカルアプリへ接続するリンクです。ブラウザのリンクからPC上のプログラムを自動起動することはできません。接続できない場合は、先に起動用ファイルを開いてください。

計算と保存先

解析はアプリを起動したPCのソルバーで実行します。STEP、設定、計算結果はそのPCに保存され、画面の「このPCで計算・保存」で接続状態を確認できます。別のPCで使う場合は、そのPCでもアプリをダウンロードして起動してください。

v0.1.2では、そのPCのメモリ容量と空き容量に応じて計算規模の上限を設定し、計算中も使用量を監視します。メッシュ設定欄で検出値を確認できます。更新時は旧版の計算と起動用ターミナルを終了し、新しいZIPを別フォルダに展開して起動してください。
